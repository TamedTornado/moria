# Moria

Moria is a reusable voxel-world substrate for Rust and Bevy consumers.

This branch is the clean planning baseline for rebuilding Moria. It deliberately
contains no inherited design document, TDD, issue decomposition, implementation,
assets, or tests from the superseded Product One pipeline.

The approved planning chain is:

1. [`docs/seeds/README.md`](docs/seeds/README.md) defines the authority of the
   retained source documents.
2. [`docs/vision.md`](docs/vision.md) records the human-approved product scope.
3. [`docs/product-vision.md`](docs/product-vision.md) is the standalone product
   vision synthesized from that scope and the retained sources.

The next generated artifact is a new product design document. Historical
engineering and build-system dogfooding evidence is retained separately under
[`docs/history/`](docs/history/) and is not evidence of the implementation on
this clean branch.
